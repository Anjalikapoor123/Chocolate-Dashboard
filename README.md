# Chocolate-Dashboard

An interactive dashboard to analyze Chocolate Sales data by Product, Sales Person, Country and Date.

Built with **Python, Pandas & Streamlit**.

## ✨ Features
- Filter data by Product, Sales Person, Country and Date
- View Total Amount, Total Boxes Shipped, Revenue Per Box and Average Sale
- Interactive and easy-to-use sidebar filters
- Real-time updates on every filter selection

## 🛠️ Tech Stack
- Python
- Pandas
- Streamlit
